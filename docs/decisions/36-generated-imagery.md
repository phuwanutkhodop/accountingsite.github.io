Every image uses the locked palette tokens, so it recolours with day/night. A Colour / Duotone / B&W switch tests treatments on the image tabs. Initials "FN" and "EST. 2026" are placeholders until the firm's name and founding year are given.

**Technical notes (Claude):** all images are inline SVG (turbulence, lighting and blur filters; procedural guilloche curves), so they weigh a few KB, need no licence and can be generated by the builder at publish time. "Illustrations" stay banned (#33): the library is materials, light, letterforms and engraving, never drawn scenes or icons.

# Fonts used by the brand toolchain

All are from Google Fonts and licensed under the SIL Open Font License 1.1. The licence texts are in this folder. The OFL allows the fonts to be kept and shared with this project.

## Fonts the locked designs use

| File | Font | Licence |
|---|---|---|
| `BM700.ttf` | Bodoni Moda Bold, optical size 11 (static instance, Google Fonts v28). Used for the letters D and A. | `OFL-BodoniModa.txt` |
| `CG600.ttf` | Cormorant Garamond SemiBold (Google Fonts v21). Used for the name. | `OFL-CormorantGaramond.txt` |

## Fonts loaded by the exploration modules

The exploration modules load these when the scripts start. They are needed to run the scripts unchanged, but no locked design uses them.

| File | Font | Licence |
|---|---|---|
| `BM700i.ttf` | Bodoni Moda Bold Italic | `OFL-BodoniModa.txt` |
| `CG700.ttf` | Cormorant Garamond Bold | `OFL-CormorantGaramond.txt` |
| `Cinzel700.ttf` | Cinzel Bold | `OFL-Cinzel.txt` |
